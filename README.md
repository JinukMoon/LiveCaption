# LiveCaption

폰 마이크로 들리는 영어를 실시간 자막으로 받아 적고 바로 한국어로 번역하는 웹앱.
Zoom 회의(노트북 스피커 옆에 폰을 둠)나 학회 발표·질의응답에서 쓰려고 만들었다.

**주소: https://jinukmoon.github.io/LiveCaption/**

## 화면

- 확정된 문장: **한국어 크게**, 영어 원문은 그 밑에 작게 (숫자·이름·용어 확인용)
- 맨 아래: 지금 말하는 중인 영어가 실시간으로 올라오고, 문장이 길어지면 회색으로 미리 번역이 붙는다
- 강의처럼 쉬지 않고 이어 말해도 마침표·물음표마다 한 문장씩 확정해서 번역한다 (문장이 끝나고 약 2초 안)
- 위로 스크롤해 지난 문장을 읽는 동안에는 자동 스크롤이 멈추고 `↓ 최신` 버튼이 뜬다
- 오른쪽 위 칩: 지금 쓰는 번역 엔진 (`Gemini` / 주황색 `Google 번역` = 대체 중)

## 처음 설정

1. 설정 링크(`…/LiveCaption/#el=<ElevenLabs 키>&gm=<Gemini 키>`)를 연다 — PC 화면의 QR을 폰 카메라로 찍으면 된다.
   키는 그 기기 브라우저에만 저장되고, `#` 뒤는 서버로 전송되지 않는다.
2. **갤럭시(크롬)**: 그 상태에서 크롬 메뉴 ⋮ → `홈 화면에 추가`(또는 `앱 설치`). 설치된 앱은 크롬과 저장소를
   공유하므로 키가 그대로 있다. 삼성 인터넷으로 열렸다면 삼성 인터넷에서 설치해도 된다(같은 브라우저에서 설치할 것).
3. 아이폰은 홈 화면 앱이 Safari와 저장소가 분리돼 있어서, 앱 안 ⚙︎ 설정 → 키 칸에 설정 링크를 통째로 붙여넣고 저장한다.
4. Gemini 키는 선택. 없거나 크레딧이 떨어지면 자동으로 무료 Google 번역을 쓴다(전문용어는 Gemini가 더 정확).

## 쓰는 법

- `듣기 시작` → 폰을 소리 나는 쪽에 둔다. 화면은 켜진 채로 유지된다(Wake Lock).
  화면 꺼짐 방지가 안 되는 기기면 경고가 뜬다 → 갤럭시: 설정 > 디스플레이 > 화면 자동 꺼짐 시간을 가장 길게.
- 30분~1시간 연속으로 켜 둬도 된다. 연결이 끊기면 자동 재연결하고, 그동안 들어온 소리(최대 15초)는 이어서 보낸다.
- 다른 앱으로 넘어가거나 화면이 잠겨 마이크가 끊기면 → 돌아와서 화면을 한 번 탭하면 다시 듣는다.
  통화·Siri가 마이크를 잠깐 막으면 `마이크 막힘`이 뜨고, 풀리면 저절로 이어진다.
- 자막 기록은 기기에 남는다(새로고침해도 유지, 약 1500문장).
- 아래 `공유`: 지금 화면의 자막 전체(한국어 + 영어 원문)를 폰 공유 창으로 보낸다 → 카톡 `나와의 채팅`, 메모 앱 등.
  공유 창이 없는 브라우저에서는 클립보드에 복사된다.
- 아래 `지우기`: 새 회의·새 발표를 시작할 때 화면을 비운다. 듣는 중에 눌러도 듣기는 계속된다.
  잘못 눌렀으면 위에 뜬 알림을 8초 안에 탭하면 되돌아온다.
- 설정 → `전문용어`: 음성 인식과 번역 둘 다에 힌트로 들어간다. 인식 힌트는 20자 이하·50개까지만 쓰인다.

## 비용

- ElevenLabs Scribe v2 Realtime: 듣고 있는 동안 흐른 오디오 시간만큼 (약 $0.39/시간 + 용어 힌트 약 $0.05/시간)
- Gemini 3.5 Flash-Lite 번역: 시간당 몇 센트 수준 / Google 번역 대체: 무료
- 데이터: 업로드 약 150 MB/시간 (16 kHz 음성). 해외 로밍 데이터로 쓸 때 주의

## 구조

| 파일 | 역할 |
|---|---|
| `index.html`, `app.css` | 화면 |
| `app.js` | 토큰 발급 → Scribe WebSocket, 자막/번역 표시, 재연결, 설정 |
| `worklet.js` | 마이크 소리를 16 kHz PCM16으로 줄여 100 ms씩 넘기는 AudioWorklet |
| `tests/e2e.py` | 가짜 마이크(WAV)로 실제 API까지 도는 Chromium 테스트 |

빌드 없음. 정적 파일 그대로 GitHub Pages(`main` 브랜치 루트)로 배포된다.
