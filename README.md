# LiveCaption

폰 마이크로 들리는 영어를 실시간 자막으로 받아 적고 바로 한국어로 번역하는 웹앱.
Zoom 회의(노트북 스피커 옆에 폰을 둠)나 학회 발표·질의응답에서 쓰려고 만들었다.

**주소: https://jinukmoon.github.io/LiveCaption/**

## 화면

- 확정된 문장: **한국어 크게**, 영어 원문은 그 밑에 작게 (숫자·이름·용어 확인용)
- 맨 아래: 지금 말하는 중인 영어가 실시간으로 올라오고, 문장이 길어지면 회색으로 미리 번역이 붙는다
- 위로 스크롤해 지난 문장을 읽는 동안에는 자동 스크롤이 멈추고 `↓ 최신` 버튼이 뜬다
- 오른쪽 위 칩: 지금 쓰는 번역 엔진 (`Gemini` / 주황색 `Google 번역` = 대체 중)

## 처음 설정

1. 설정 링크(`…/LiveCaption/#el=<ElevenLabs 키>&gm=<Gemini 키>`)를 연다. 키는 그 기기 브라우저에만 저장되고, `#` 뒤는 서버로 전송되지 않는다.
2. 아이폰 **홈 화면 앱은 Safari와 저장소가 분리**돼 있다. 홈 화면에 추가했다면 그 앱 안에서
   ⚙︎ 설정 → 키 칸에 **설정 링크를 통째로 붙여넣고 저장**하면 키 두 개가 같이 들어간다.
3. Gemini 키는 선택. 없거나 크레딧이 떨어지면 자동으로 무료 Google 번역을 쓴다(전문용어는 Gemini가 더 정확).

## 쓰는 법

- `듣기 시작` → 폰을 소리 나는 쪽에 둔다. 화면은 켜진 채로 유지된다(Wake Lock).
- 다른 앱으로 넘어가거나 전화가 오면 iOS가 마이크를 끊는다 → 돌아와서 화면을 한 번 탭하면 다시 듣는다.
- 네트워크가 잠깐 끊기면 자동 재연결하고, 그동안 들어온 소리(최대 8초)는 이어서 보낸다.
- 자막 기록은 기기에 남는다(새로고침해도 유지). 설정 → `기록 지우기`.
- 설정 → `전문용어`: 음성 인식과 번역 둘 다에 힌트로 들어간다. 인식 힌트는 20자 이하·50개까지만 쓰인다.

## 비용

- ElevenLabs Scribe v2 Realtime: 듣고 있는 동안 흐른 오디오 시간만큼 (약 $0.39/시간 + 용어 힌트 약 $0.05/시간)
- Gemini 3.5 Flash-Lite 번역: 시간당 몇 센트 수준 / Google 번역 대체: 무료

## 구조

| 파일 | 역할 |
|---|---|
| `index.html`, `app.css` | 화면 |
| `app.js` | 토큰 발급 → Scribe WebSocket, 자막/번역 표시, 재연결, 설정 |
| `worklet.js` | 마이크 소리를 16 kHz PCM16으로 줄여 100 ms씩 넘기는 AudioWorklet |
| `tests/e2e.py` | 가짜 마이크(WAV)로 실제 API까지 도는 Chromium 테스트 |

빌드 없음. 정적 파일 그대로 GitHub Pages(`main` 브랜치 루트)로 배포된다.
